# 拖延之门 MVP

一个通过轻量交互打断无意识刷屏的 Android 原型。

## 当前功能

- 从已安装应用中选择需要干预的目标 App
- 支持“打开时立即触发”，或连续使用 1 / 5 / 10 / 15 / 20 分钟后触发
- App 选择器支持搜索、字母排序和右侧字母快速定位
- 使用悬浮层展示几乎全屏的“门”
- 沿 S 形轨迹描摹后继续使用
- 一键跳转到用户选择的替代活动
- 长按紧急绕过，暂停干预 30 分钟
- 数据完全保存在本机
- 不使用无障碍服务

## 构建

环境要求：JDK 17+、Android SDK 35。

```powershell
./gradlew.bat assembleDebug
```

安装包输出：

`app/build/outputs/apk/debug/app-debug.apk`

## 首次使用

1. 选择目标 App 和替代活动。
2. 授予“使用情况访问权限”。
3. 授予“显示在其他应用上层”权限。
4. Android 13 及以上允许运行状态通知。
5. 点击“开始守门”。

## MVP 限制

- 各厂商系统的后台限制可能导致监控服务被终止，需要允许应用后台运行。
- 为便于测试，最短触发间隔提供 1 分钟。
- 支持多个目标 App、独立规则与独立出口。
- 守门开启时，应用更新或设备重启后会在权限有效的前提下自动恢复。
- 设置页提供服务心跳、权限、电池优化和厂商后台管理诊断。
